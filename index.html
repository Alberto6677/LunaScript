Le manifeste

Notre langue, notre code

Coder en français, c'est penser en français. Pas de traduction, pas de friction. Juste de la logique pure exprimée dans nos mots.

Accessible à tous

Du lycéen curieux au développeur confirmé, LunaScript se lit naturellement. Pas de jargon inutile, pas de complexité artificielle.

Simple mais efficace

Une ligne de CDN et vous codez. Pas de NodeJS, pas de build, pas de config. LunaScript vous attends y'a plus qu'a.

Construit ensemble

LunaScript est OpenSource pour que vous aussi vous puissiez contribuer a votre langage !

Voyez par vous-même

Du code qui se lit comme on pense

exemple.ls
LunaScript v0.1 
def nom = "MrAlberto"
msg(nom)

repeter 3 {
    msg("Salut depuis LunaScript")
}

si (nom == "MrAlberto") {
    msg("Bienvenue, créateur")
} sinon {
    msg("Bienvenue, visiteur")
}
Console
> MrAlberto
> Salut depuis LunaScript
> Salut depuis LunaScript
> Salut depuis LunaScript
> Bienvenue, créateur
